# Гардемарины

Сайт флота GARDEMARINES [GDM] в World of Warships Legends. На главной собраны история турниров, состав на радаре и статистика игроков.

## Как устроено

- `index.html` — главная и источники данных для радара, сводки и таблицы.
- `archive.html` — страницы результатов турниров. У каждого турнира есть прямая ссылка с якорем. Для Risers Cup 26 сохранены матчи и показатели по картам.
- `site.css` — стили главной и турнирных страниц.
- `CNAME` — пользовательский домен для GitHub Pages.

## Как запустить

```bash
python -m http.server 8000
```

Страница открывается по адресу http://localhost:8000. Сборка не нужна.

## Как обновлять

Список актуальных турниров начинается в разделе `#season`. Для завершённого турнира добавьте строку в сводку и карточку результата с тем же якорем на странице подробностей.

Показатели игроков взяты из игрового списка. Среднее и медиана вычислены по отображаемым личным процентам, мода — по повторениям этих процентов. После смены состава обновите записи радара и таблицы, пересчитайте сводку и проверьте совпадение ников.

Перед публикацией проверьте прямые ссылки турниров, таблицу на узком экране и работу радара. Слияние PR в `main` происходит после просмотра и согласования.
