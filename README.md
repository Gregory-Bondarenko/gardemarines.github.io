# Гардемарины

Сайт флота GARDEMARINES [GDM] в World of Warships Legends. На главной — состав флота на радаре и текущий турнирный сезон. В архиве — результаты прошлых лет и хронология Risers Cup 26.

## Как устроено

- `index.html` — главная, состав флота и сезон 2027.
- `archive.html` — история турниров и матчи Risers Cup 26.
- `site.css` — стили обеих страниц.
- `CNAME` — домен gardemarines.ru для GitHub Pages.

## Как запустить

```bash
python -m http.server 8000
```

Откройте http://localhost:8000. Сборка и установка пакетов не нужны.

## Как обновлять турниры

После объявления турнира добавьте его в раздел `#season` на главной. Для подробной страницы используйте прямую ссылку. Завершённые турниры добавляйте в архив с датой и результатом.

Перед публикацией проверьте главную и архив на телефоне и десктопе, прямой переход на `archive.html#risers-cup-26` и работу радара. Покажите изменения в PR. Публикация идёт из `main` после согласования.
