# Гардемарины

Сайт флота GARDEMARINES [GDM]. Главная содержит историю турниров, радар состава и агрегированную статистику 45 игроков. Страница Risers Cup 26 содержит матчи и результаты по картам.

## Запуск

Запустите `python -m http.server 8000` в корне репозитория и откройте http://localhost:8000.

## Обновление

Добавляйте результат турнира в список его сезона. Ссылку добавляйте, когда готовы подробности. При изменении состава обновите ники радара и пересчитайте сводку по игровым данным.
